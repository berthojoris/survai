# Survai

Digital field survey platform — mobile-first.

## Pages

| File | Description |
|------|-------------|
| login.html | Login page |
| dashboard.html | Dashboard with stats and assignments |
| survey.html | Survey-taking interface (12 questions) |
| report.html | Analytics and reporting |

## Design

- Dark theme based on Trae.ai color palette
- Mobile-first (max-width 430px)
- Zero dependencies — pure HTML/CSS/JS
- Indonesian language UI
